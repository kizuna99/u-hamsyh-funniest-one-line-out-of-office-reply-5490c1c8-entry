A Python program (`main.py`) that writes one funny one-line out-of-office
reply to `/output/entry.txt`:

> I'm out of office until Monday: this reply is on, my brain is off, and only one of us is coming back.

Run it with:

```sh
python3 main.py
```

The line is a single line of UTF-8 text within the competition's
1–160 character gate, chosen for an instant first-read laugh, a fresh
twist on the usual away message, and a length you can take in at a glance.
